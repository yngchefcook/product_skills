# Генерация изображений инструментом

Использовать этот маршрут, когда встроенной библиотеки недостаточно, пользователь
просит уникальный визуал или сюжет требует предметной сцены.

## Точные имена инструментов

- Текущий встроенный инструмент: `image_gen`; полное имя вызываемой функции в
  реестре инструментов — `image_gen.imagegen`.
- Совместимый MCP-инструмент прежних runtime: `generate-image`.
- Не вызывать эти имена как Python-функции. Это инструменты агентного runtime,
  которые нужно запустить до `build_from_spec()`.

Сначала проверить доступные инструменты. Предпочитать `image_gen.imagegen`; если
его нет, но доступен `generate-image`, использовать совместимый маршрут ниже.

## Маршрут `image_gen.imagegen`

Для нового изображения вызвать инструмент с:

- `prompt`: production-ready описание;
- не передавать `referenced_image_paths` и `num_last_images_to_include`.

Для редактирования локального изображения сначала визуально его проверить, затем
передать `referenced_image_paths`. Для изображения только из контекста
разговора использовать минимальное достаточное `num_last_images_to_include`.
Никогда не передавать оба механизма одновременно.

После генерации:

1. визуально проверить композицию, артефакты, текст и ограничения;
2. сохранить выбранный результат в рабочую директорию;
3. передать локальный путь в поле `image` слайда;
4. не оставлять используемый презентацией файл только во временном хранилище.

## Совместимый маршрут `generate-image`

Вызвать MCP `generate-image` с:

- `prompt`;
- `width_ratio` и `height_ratio`;
- опциональным `seed` для воспроизводимых вариаций.

Инструмент возвращает публичный HTTP(S) URL. Передать его в поле `image_url`.
Builder скачает изображение с таймаутом, ограничит размер 25 МиБ, проверит
растр через Pillow и встроит его в PPTX.

Если URL недоступен из runtime, сохранить изображение локально и использовать
поле `image`.

## Пропорции

- `16:9`: обложка, разделитель, полноэкранный фон, финальный слайд;
- `4:3` или `1:1`: боковой визуал на контентном слайде;
- один вызов инструмента на каждый самостоятельный сюжет или вариант.

Просить negative space со стороны текста. Не генерировать логотипы, названия
организаций, читаемый синтетический текст, водяные знаки, фальшивые интерфейсы
или изображения, которые выглядят как реальные графики и данные.

## Каркас промпта

```text
Use case: productivity-visual
Asset type: presentation visual, 16:9
Primary request: <сюжет и смысл>
Scene/backdrop: <среда>
Subject: <главный объект>
Style/medium: premium editorial photography or restrained 3D illustration
Composition/framing: <положение объекта>; negative space on <side>
Lighting/mood: <свет и настроение>
Color palette: <3–5 цветов>
Constraints: no logos, no company names, no readable text, no watermark
Avoid: fake UI, fake charts, generic stock-photo look, visual clutter
```

Сохранять финальный prompt рядом с рабочими материалами презентации, чтобы
визуал можно было воспроизвести или точечно изменить.
