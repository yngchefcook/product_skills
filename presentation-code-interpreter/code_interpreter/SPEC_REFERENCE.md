# Presentation spec schema

## Содержание

1. Корень spec
2. Общие поля
3. Типы слайдов
4. Полный пример

## 1. Корень spec

```python
spec = {
    "filename": "executive_brief.pptx",
    "theme": "midnight",  # midnight | paper | warm | forest
    "slides": [...],
}
```

`theme` также принимает:

```python
{
    "base": "paper",
    "overrides": {
        "accent": "#5B5BD6",
        "dark": "#161A2B",
    },
}
```

Не менять шрифты на отсутствующие в runtime.

## 2. Общие поля

Большинство слайдов поддерживает:

- `title`: заголовок-вывод;
- `eyebrow`: короткая метка главы;
- `source`: компактная строка источника;
- `image`: ID из каталога или путь к локальному файлу;
- `image_url`: альтернативный HTTP(S) URL, например результат MCP
  `generate-image`; не использовать одновременно с `image`;
- `focal_x`, `focal_y`: точка фокуса изображения от `0.0` до `1.0`.

Для генерации нового визуала сначала выполнить workflow из
`IMAGE_GENERATION.md`, затем передать либо локальный `image`, либо удалённый
`image_url`.

## 3. Типы слайдов

### title

```python
{
    "type": "title",
    "title": "Стратегия превращает неопределённость в последовательность решений",
    "subtitle": "Контекст, выбор и план действий",
    "kicker": "EXECUTIVE BRIEF",
    "meta": "Июль 2026",
    "image": "strategic_choices",
}
```

### section

```python
{
    "type": "section",
    "number": "02",
    "title": "Решение начинается с правильной рамки",
    "subtitle": "От симптомов к первопричине",
    "image": "cloud_compute_landscape",
}
```

### statement

```python
{
    "type": "statement",
    "eyebrow": "ГЛАВНЫЙ ТЕЗИС",
    "title": "Сложность уменьшается, когда решения принимаются в правильном порядке",
    "body": "Сначала цель, затем критерии, только после этого — инструменты.",
    "dark": False,
}
```

### bullets

```python
{
    "type": "bullets",
    "title": "Три ограничения определяют качество результата",
    "lead": "Все остальные решения следуют из них.",
    "bullets": ["Ограничение 1", "Ограничение 2", "Ограничение 3"],
}
```

Максимум пять буллетов.

### image

```python
{
    "type": "image",
    "title": "Человек задаёт направление, AI ускоряет исследование вариантов",
    "body": "Роль технологии — увеличить качество выбора, а не скрыть его.",
    "bullets": ["Контекст", "Критерии", "Контроль"],
    "image": "ai_human_collaboration",
    "image_side": "right",
}
```

Вариант с URL, возвращённым инструментом:

```python
{
    "type": "image",
    "title": "Новый визуал раскрывает тезис без дополнительного текста",
    "body": "Builder проверит и встроит удалённое изображение.",
    "image_url": "https://example.invalid/generated-visual.png",
    "image_side": "right",
}
```

`example.invalid` — только обозначение поля; использовать реальный URL,
возвращённый инструментом.

### metrics

```python
{
    "type": "metrics",
    "title": "Три показателя дают полную картину прогресса",
    "metrics": [
        {"value": "42%", "label": "Скорость", "detail": "Изменение к базе"},
        {"value": "3,1×", "label": "Качество", "detail": "Относительный индекс"},
        {"value": "−18%", "label": "Риск", "detail": "Снижение отклонений"},
    ],
    "source": "Источник: данные пользователя",
}
```

Использовать от двух до четырёх показателей.

### chart

```python
{
    "type": "chart",
    "title": "Основной сценарий создаёт устойчивый разрыв к базе",
    "chart_type": "line",  # column | bar | line | pie
    "categories": ["2023", "2024", "2025", "2026П"],
    "series": [
        {"name": "База", "values": [100, 106, 111, 116]},
        {"name": "Основной сценарий", "values": [100, 112, 128, 149]},
    ],
    "unit": "Индекс, 2023 = 100",
    "insight": "К 2026 году разрыв достигает 33 пунктов.",
    "source": "Источник: расчёт на данных пользователя",
}
```

Для `pie` передавать ровно одну серию и не более шести категорий.

### comparison

```python
{
    "type": "comparison",
    "title": "Новый подход переносит усилие с исправлений на предотвращение",
    "left": {
        "heading": "Раньше",
        "lead": "Реактивная модель",
        "items": ["Поздний сигнал", "Ручная сверка", "Непредсказуемый результат"],
    },
    "right": {
        "heading": "Теперь",
        "lead": "Управляемая модель",
        "items": ["Ранний сигнал", "Единые критерии", "Повторяемый результат"],
    },
}
```

### timeline / process

```python
{
    "type": "process",
    "title": "Пять шагов переводят идею в измеримый результат",
    "steps": [
        {"label": "01", "title": "Цель", "detail": "Определить исход"},
        {"label": "02", "title": "Факты", "detail": "Собрать основу"},
        {"label": "03", "title": "Выбор", "detail": "Сравнить варианты"},
        {"label": "04", "title": "Запуск", "detail": "Назначить владельцев"},
        {"label": "05", "title": "Контроль", "detail": "Измерить эффект"},
    ],
}
```

Максимум пять этапов.

### quote

```python
{
    "type": "quote",
    "quote": "Короткая проверяемая цитата, которая меняет понимание темы.",
    "attribution": "Имя автора",
    "role": "Роль или источник",
    "source": "Источник: прямая ссылка или файл, страница",
    "image": "investment_horizon",
}
```

Не создавать вымышленные цитаты.

### table

```python
{
    "type": "table",
    "title": "Вариант B лидирует по двум критериям из трёх",
    "columns": ["Вариант", "Эффект", "Срок", "Риск"],
    "rows": [
        ["A", "Средний", "3 мес.", "Низкий"],
        ["B", "Высокий", "4 мес.", "Средний"],
        ["C", "Высокий", "8 мес.", "Высокий"],
    ],
    "highlight_row": 1,
    "source": "Источник: оценка рабочей группы",
}
```

Ориентир: до восьми столбцов и девяти строк.

### summary

```python
{
    "type": "summary",
    "title": "Решение готово к переходу в план",
    "takeaway": "Выбранный вариант сочетает максимальный эффект с управляемым риском.",
    "actions": ["Подтвердить владельца", "Зафиксировать срок", "Запустить пилот"],
}
```

### closing

```python
{
    "type": "closing",
    "title": "Следующий шаг — подтвердить пилот и критерии успеха",
    "subtitle": "Решение сегодня позволяет начать в следующем цикле.",
    "contact": "Владелец · дата · канал связи",
    "image": "closing_horizon",
}
```
